# Mint Player — 개인용 Android 음악 앱 / 0.1.0

**상태: 네이티브 Android 소스 프로젝트입니다. 이 ZIP은 설치 파일이 아닙니다. 빌드 및 실기기 동작 검증은 아직 수행하지 않았습니다.**

## 디자인
차콜 배경, 민트색 재생 버튼, 둥근 음원 카드와 하단 고정 플레이어. 모던 휴대용 MP3 플레이어에서 착안한 독자적인 UI입니다. 특정 상용 제품의 화면이나 자산을 복제하지 않습니다.

## 포함된 구현
- Android 8 이상, MediaStore의 기기 오디오 검색 및 시스템 파일 선택기로 다중 가져오기
- 제목/아티스트/앨범 검색과 정렬, 즐겨찾기
- 플레이리스트 만들기/이름 변경/삭제, 곡 추가/제거/위아래 이동
- 재생/일시정지/이전/다음/탐색, 셔플, 전체 및 한 곡 반복
- 재생 서비스, 잠금 화면/알림 미디어 컨트롤, 오디오 포커스, 이어폰 연결 해제 시 정지
- 실제 재생 세션의 FFT 시각화 (권한과 기기 오디오 효과 지원 필요)
- 보관함/즐겨찾기/플레이리스트의 기기 내 저장
- 로그인, 광고, 서버, 인터넷 권한 없음. 원본 파일 수정/이동/삭제 없음

## APK 만들기 — 방법 A: Android Studio
1. PC에 Android Studio를 설치합니다. ZIP을 풀고 `settings.gradle`이 있는 MintPlayer 폴더를 엽니다.
2. 프로젝트 Gradle JDK는 17, Gradle 버전은 8.9를 사용합니다. Gradle wrapper는 포함하지 않았습니다. IDE가 wrapper를 요구하면 Gradle 8.9를 준비한 후 프로젝트 폴더에서 `gradle wrapper --gradle-version 8.9`를 실행하고 다시 엽니다.
3. Android SDK 35를 설치하고 Gradle 동기화를 완료합니다. 최초 준비에는 인터넷이 필요합니다.
4. Build 메뉴의 APK 생성 기능 또는 `gradle assembleDebug`를 실행합니다.
5. 설치 파일은 `app/build/outputs/apk/debug/app-debug.apk`입니다. 개인용 디버그 서명이 자동으로 들어갑니다.

## APK 만들기 — 방법 B: GitHub Actions
1. 개인 GitHub 계정에 **비공개 저장소**를 만듭니다. GitHub는 앱 스토어가 아니라 빌드를 위한 선택적 개발 서비스입니다.
2. ZIP 내부 MintPlayer 폴더의 내용 전체를 저장소 최상위에 올립니다. `.github/workflows/apk.yml` 숨김 폴더도 포함해야 합니다. 음악 파일은 올리지 마세요.
3. Actions의 `Build private APK`를 실행합니다. 성공하면 `MintPlayer-installable-APK` 산출물을 다운로드합니다.
4. 산출물 ZIP을 풀면 `app-debug.apk`가 있습니다. 워크플로 실행 환경에서 SDK/빌드 도구를 준비하므로 빌드 실패 시 해당 로그를 확인해야 합니다.
5. GitHub 사용 가능 여부와 이용 요금은 계정 정책에 따릅니다. 원하지 않으면 방법 A만 사용하세요.

### 업데이트 서명 주의
GitHub의 임시 빌드 환경은 실행마다 서명이 달라질 수 있습니다. 동일한 앱 위에 업데이트 설치하려면 **같은 서명 키**를 계속 사용해야 합니다.
- PC에서 계속 빌드할 때는 동일한 사용자 계정의 debug.keystore를 보관하세요.
- GitHub에서 연속 업데이트하려면 표준 Android 디버그 키스토어(별칭 `androiddebugkey`, 기본 비밀번호 `android`)를 Base64로 인코딩하여 저장소 Actions secret `MINT_DEBUG_KEYSTORE_BASE64`로 저장하세요. 워크플로가 이를 복원합니다. 키를 공개 저장소나 채팅에 올리지 마세요.
- 서명이 다르면 기존 앱 삭제 후 설치해야 하며, 앱 삭제 시 즐겨찾기/플레이리스트가 지워집니다. 원본 음원은 유지됩니다. 반복 사용할 앱은 장기 보관하는 개인 릴리스 키로 서명하는 방식을 권장합니다.

## 폰에 설치
1. APK를 USB, 메신저 또는 개인 파일 공유로 폰에 전달합니다.
2. APK를 열고 파일 관리자/메신저에 대해 ‘이 출처의 앱 설치 허용’을 요청받으면 허용합니다. Android 버전에 따라 메뉴 이름이 다를 수 있습니다.
3. 설치 후에는 해당 출처의 설치 권한을 다시 끄는 것을 권장합니다. Play Protect를 일괄 해제하지 마세요.
4. 앱을 열고 알림 권한을 선택한 뒤 ‘기기 검색’의 음악 접근 권한을 허용합니다. 권한 없이도 ‘파일 가져오기’를 쓸 수 있습니다.
5. 곡을 탭하면 재생합니다. 길게 누르면 즐겨찾기/플레이리스트 관리 메뉴가 나옵니다.
6. 시각화 영역이나 하단 ‘시각화 설정’을 누르면 비주얼라이저 권한을 요청합니다.

## 권한과 개인정보
- 음악 권한: Android 미디어 목록에서 음악을 검색할 때만 사용합니다.
- 마이크 권한: Android Visualizer API가 요구합니다. 소스는 MediaRecorder/AudioRecord를 사용하지 않으며 마이크 녹음이나 녹음 저장을 하지 않습니다. 거절 시 정적인 선이 표시됩니다. 가짜 음악 반응 애니메이션으로 대체하지 않습니다.
- 알림 권한: 미디어 재생 제어를 표시하기 위한 요청입니다.
- 앱 데이터 자동 백업은 꺼져 있습니다. 앱 삭제/데이터 초기화 시 목록을 잃을 수 있으므로 주의하세요. 목록 내보내기 기능은 이번 버전에 없습니다.

## 알려진 범위 및 한계
- MP3/AAC/FLAC/WAV 등은 Android 기기에서 지원하는 코덱 범위 내에서 재생합니다. DRM 음원, 스트리밍 서비스의 암호화된 다운로드는 지원하지 않습니다.
- 기기 검색은 MediaStore에 등록된 오디오를 가져옵니다. 모든 폴더를 강제로 재귀 탐색하거나 타 앱의 전용 저장소를 읽지 않습니다. 숨겨진 파일은 직접 가져오세요.
- 같은 실제 파일을 기기 검색과 파일 선택기로 각각 추가하면 URI가 달라 중복 표시될 수 있습니다.
- 파일 삭제/이동/SD카드 분리 후에는 해당 곡을 재생하지 못할 수 있습니다. 보관함에서 제거하고 다시 가져오세요. 자동 파일 변경 감시 기능은 없습니다.
- 즐겨찾기와 목록은 유지하지만 재생 위치/대기열/셔플 설정의 재부팅 후 복원은 구현하지 않았습니다.
- 아티스트/앨범별 정렬은 제공하지만 별도의 앨범 표지 그리드, 태그 편집, 이퀄라이저, 폴더별 브라우징은 포함하지 않습니다.
- 시각화는 기기 오디오 효과 구현에 따라 동작하지 않을 수 있습니다. 시스템 권한이 있어도 제조사가 지원하지 않을 수 있습니다.
- 대규모 라이브러리의 행 가상화는 구현하지 않았으므로 수천 곡 환경은 추가 최적화가 필요합니다.
- 앱 강제 종료, 재부팅, 제조사 절전 정책 등에 의해 백그라운드 재생이 종료될 수 있습니다.
